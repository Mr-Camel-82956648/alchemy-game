# frontend/tools

这个目录用于放置本地调试、预览、调参和临时校验工具。

核心约定：

- 默认不接正式首页，也不属于正式玩家流程。
- 这里只在需要视觉调试、参数校准或专项核查时按需进入；平时正常业务开发不要主动把整个 `frontend/tools/` 带入上下文。
- 工具页面应尽量保持独立，避免侵入正式运行逻辑。
- 工具可按当前开发需要保留，也可以在确认无用后再清理。
- 新增工具时，优先采用独立页面或独立脚本，而不是把临时入口接进正式流程。
- 如果某个工具已经失去使用价值，应在确认后删除，而不是长期作为隐性正式功能保留。

当前说明：

- `monster_facing_preview.html` / `monster_facing_preview.js` 是怪物朝向与镜像的本地预览工具。
- 该工具当前保留用于正式怪物朝向复查，不接正式首页。
- `arena_glyph_tuner.html` / `arena_glyph_tuner.js` 是竞技场法阵视觉调试页，用于核查尺寸、位置、混合模式与近似后处理参数，不直接修改 battle 正式渲染逻辑。
